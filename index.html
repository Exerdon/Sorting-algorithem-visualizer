Bubble Sort

Repeatedly compares adjacent values and swaps out-of-order pairs.

Average timeO(n²)
Extra spaceO(1)

Selection Sort

Finds the minimum value in the unsorted section and moves it to the front.

Average timeO(n²)
Extra spaceO(1)

Insertion Sort

Builds a sorted section by inserting each new value into its position.

Average timeO(n²)
Extra spaceO(1)

Merge Sort

Divides the array, sorts each half recursively, then merges them.

Average timeO(n log n)
Extra spaceO(n)

Quick Sort

Partitions values around a pivot and sorts the smaller sections.

Average timeO(n log n)
Extra spaceO(log n)*

Heap Sort

Builds a max heap and repeatedly moves its maximum to the end.

Average timeO(n log n)
Extra spaceO(1)**

* Quick Sort recursion is O(n) in the worst case. ** Typical in-place Heap Sort. Animation counters count algorithm operations, not wall-clock performance.
